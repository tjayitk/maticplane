## Tipos de Hospedagem Disponíveis

### Hospedagem Compartilhada

O ponto de entrada. Boa para sites institucionais, blogs, portfólios e projetos em fase inicial. Você sobe o site em um clique, tem SSL grátis incluso, backup diário automático e segurança 24/7. Uptime garantido de 99,9% — o que, na prática, significa que o site fica fora do ar menos de 9 horas por ano, se tanto.

### Hospedagem WordPress Gerenciada

Aqui a MaticPlane faz o trabalho pesado: atualizações automáticas, staging grátis (aquele ambiente de teste antes de mandar qualquer mudança para o site de verdade), ferramentas de performance e escala automática. Perfeito para quem quer focar no conteúdo e não em configuração de servidor.

Se você usa WordPress para monetizar — seja blog, loja com WooCommerce ou site para cliente — essa modalidade economiza tempo e dor de cabeça.

👉 [Ver planos de Hospedagem WordPress da MaticPlane](https://maticplane.com/aff.php?aff=11)

### VPS (Servidor Virtual Privado)

Para quem precisa de mais controle e recursos dedicados. CPU, RAM e armazenamento que são seus — sem dividir com o vizinho que está rodando algum script maluco no mesmo servidor.

Indicado para e-commerces com volume relevante de transações, sistemas web, aplicações customizadas ou qualquer projeto que já sentiu o gargalo do compartilhado.

### Construtor de Sites

Para quem quer colocar um site no ar sem precisar saber uma linha de código. Arrasta, solta, publica. Mais de 40 milhões de empreendedores usam essa tecnologia no mundo. Funciona tanto para landing pages simples quanto para sites institucionais completos.
